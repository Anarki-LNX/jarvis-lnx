Setup

Three steps: language, brain, pair a device. Everything can be changed later in the admin panel.

Status

1 · Name, language and voice

The wake word stays “Hey NuOrb”. You can also rename the assistant in conversation: “From now on you are called …”.

2 · Brain

Ollama

IP address of the computer running Ollama (or its hostname, e.g. http://ollama.local:11434). Use the IP if the name doesn't resolve. Ollama on this same machine: use this machine's IP too (start Ollama with OLLAMA_HOST=0.0.0.0).

Important: Hermes requires at least 64k tokens of context. Set OLLAMA_CONTEXT_LENGTH=65536 on the Ollama server or create a model variant with “PARAMETER num_ctx”, otherwise answers get cut off.

Claude

Cost: billed per token directly by Anthropic (console.anthropic.com). A short voice question costs about 0.1–0.5 cents with Haiku, a few cents with Sonnet. Set a spending limit there.

Privacy: with Claude, conversation text is sent to Anthropic (USA). Audio always stays local.

3 · Pair a device
