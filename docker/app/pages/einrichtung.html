1 · Name, language and voice

The wake word stays “Hey NuOrb”. You can also rename the assistant in conversation: “From now on you are called …”.

2 · Brain

Local language model server

Ollama: http://:11434. llama.cpp/LocalAI usually port 8080, vLLM 8000, LM Studio 1234. Use the IP of the computer running the server, also if it is this one; the server must listen on the network (0.0.0.0) and its port must be open in that computer's firewall.

Open the port on the computer running the server, one of these, depending on its firewall:


    
    
    
    
    
Important: NuOrb needs at least 64k tokens of context. Ollama: OLLAMA_CONTEXT_LENGTH=65536, llama.cpp: -c 65536, vLLM: --max-model-len 65536, LM Studio: Context Length 65536. The model must support tool calling (llama.cpp: --jinja, vLLM: --enable-auto-tool-choice).
