Weather

Set your place once. {brand} then answers weather questions with current values, forecast and official warnings. All requests go from this server directly to the weather service.

1 · Place

Place names: Open-Meteo Geocoding, location data based on GeoNames (CC BY 4.0). Postcodes: OpenStreetMap Nominatim, © OpenStreetMap contributors (ODbL). The search runs only now, not during normal use.

2 · Source

Quelle: Deutscher Wetterdienst (CC BY 4.0), via Bright Sky. Official warnings are read out unchanged.

Weather data by Open-Meteo.com (CC BY 4.0). The free Open-Meteo API may only be used non-commercially. Personal home automation counts as non-commercial.

3 · WeatherXM station (optional)

Hyperlocal measurements from a WeatherXM station near you, with your own WeatherXM Pro API key. Forecast and warnings still come from the German Weather Service. The terms of WeatherXM apply to your account.
