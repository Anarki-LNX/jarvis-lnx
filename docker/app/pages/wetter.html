Weather

Set your place once. {brand} then answers weather questions with current values, forecast and official warnings. All requests go from this server directly to the weather service.

1 · Place

Search by the name of the place, not by postcode. Place search: Open-Meteo Geocoding, location data based on GeoNames (CC BY 4.0). The search runs only now, not during normal use.

Quelle: Deutscher Wetterdienst (CC BY 4.0), via Bright Sky. Official warnings are read out unchanged.
