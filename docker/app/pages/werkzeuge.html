Tools of the assistant

Extended tools are a risk. A web page or a document can contain hidden instructions. With shell and file access the model can then read the passwords and keys of this server or reach devices in your home network. Only switch this on if you need it and know the risk.

Rules that always apply

After the assistant has read outside content (web search, web page, file, image, an added MCP server), every action with an effect needs your confirmation on a card. This applies to the whole conversation.

Shell, Python and browser may not reach addresses in your home network. Only the addresses you entered for the brain, MCP servers and smart home are allowed.
