# AI declaration

NuOrb is developed with substantial help from AI (Anthropic's Claude, via Claude Code). We want to be upfront about that.

The maintainer is not a professional programmer. The maintainer decides what NuOrb should do and how it should feel, tests every release on their own hardware and makes the final calls. Most of the code, tests and documentation are generated by AI under the maintainer's direction.

| Area | AI involvement |
|---|---|
| Design (architecture, features, UX) | Pair: ideas and decisions by the maintainer, worked out together with AI |
| Implementation (production code) | Generated |
| Testing (end-to-end tests, test plans) | Generated: every release runs the end-to-end test suite before it is published |
| Documentation (README, install guides, release notes) | Generated |
| Review | Generated: human code reviews are very welcome, see [CONTRIBUTING.md](CONTRIBUTING.md) |
| Deployment (Docker build, CI, installer) | Generated |

Levels follow the common scheme *Hint / Assisted / Pair / Generated*.

What this means for you:

- The code has not been reviewed line by line by an experienced developer. Please treat it like any young hobby project and report problems.
- Privacy and safety rules are hard requirements, not AI suggestions: everything runs locally, no telemetry, no accounts, confirmation cards before real-world actions, ports never exposed to the internet by default.
